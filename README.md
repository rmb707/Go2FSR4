# Go2FSR4

**FSR 4.1.2 for Legion Go 2 Z2 Extreme. Secure Boot stays enabled.**

## Data

Call of Duty's native FSR 4, **Ultra Performance**, AMD frame generation, Adrenalin **26.10.1**.

| Output resolution | Render resolution | Average base FPS | Average FPS with frame generation |
|---|---|---:|---:|
| 1920 × 1200 | 1200 × 752 | 33 | 67 |
| 1280 × 800 | 800 × 496 | 55 | 109 |

Resolution was changed in Legion Go settings. Both runs use the same driver; this is a resolution comparison. [Exports and test details](docs/BENCHMARKS.md).

## Install

Download [Go2FSR4.exe](https://github.com/rmb707/Go2FSR4/releases/download/v0.1.0/Go2FSR4.exe).

**Experimental first release: live install/restore testing is incomplete.**

1. Run **Go2FSR4.exe** and approve Windows administrator access.
2. Choose **Install**, then restart.
3. Reopen the app and choose **Verify**. Select FSR in your game.

To restore your previous driver, use **Uninstall** in the same app.

Supports **Legion Go 2 Z2 Extreme / Radeon 890M**, Windows 11, starting Lenovo driver **32.0.23033.5002**. Requires internet and **12 GB free**.
